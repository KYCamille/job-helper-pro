職缺摘要

公司
光點電商 Lumen Commerce
地點
台北市信義區
型態
全職，可每週遠端 1 天
薪資
月薪 50,000–65,000 元

用 SQL 與 BI 工具追蹤電商營運指標、分析會員行為與 A/B 測試，把分析結果交給行銷與產品團隊執行。

條件拆解

必備

  • 2 年以上數據分析經驗 JD：「2 年以上數據分析相關工作經驗」
  • SQL 複雜查詢 JD：「能獨立撰寫複雜查詢」
  • BI 工具（Tableau／Looker Studio／Power BI） JD：「熟悉至少一種 BI 工具」
  • A/B 測試或實驗設計 JD：「具備 A/B 測試或實驗設計經驗」
  • 跨部門溝通 JD：「良好的跨部門溝通能力」

加分

  • Python 資料處理 JD：「熟悉 Python 進行資料處理」
  • GA4 或網站追蹤工具 JD：「熟悉 GA4」
  • 電商或零售產業經驗 JD：「電商或零售產業經驗」
  • BigQuery JD：「熟悉 BigQuery」

關鍵字

SQLDashboardTableau A/B 測試會員分群轉換率 回購率跨部門溝通Python BigQuery

總分89 / 100高度適合，建議優先投遞。

落差與補強

  • GA4（加分項，目前只用過 UA）：完成 Google Skillshop 的 GA4 入門課程，並用 GA4 示範帳戶做一張轉換漏斗報表截圖，放進作品集。
  • 線上轉換漏斗分析經驗：用公開電商資料集（例如 Kaggle 的電商行為資料）做一份「瀏覽 → 加入購物車 → 結帳」漏斗分析，寫成一頁摘要。
  • BigQuery 只有基礎：在 BigQuery 沙盒跑 5 個練習查詢（視窗函數、CTE），整理成筆記，面試時可以具體說明。

面試準備

  1. 請分享一次用數據推動業務改變的經驗。
    回答方向：E3 高價值會員喚回，說明如何定義「高價值」與「90 天」，以及 30 天回購率提升 12% 的追蹤方式。
  2. 你怎麼設計一個 A/B 測試？
    回答方向：E6 店內促銷文案測試，說明樣本（8 間門市、4 週）、指標（客單價）、以及怎麼避免門市差異影響結果。
  3. Dashboard 做完之後，怎麼確認大家真的有在用？
    回答方向：E2 會員回購儀表板，從每週 6 小時降到 1.5 小時，並說明怎麼蒐集店長回饋。
  4. 門市經驗要怎麼轉到電商？
    回答方向：會員分群（RFM）、回購率與客單價是共通指標；補充自學的漏斗分析（見落差與補強）。
