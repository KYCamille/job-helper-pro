# 求職小幫手 Pro｜Job Helper Pro

「求職小幫手」的進階版。一樣用 **AGENTS.md 規則驅動**，但每則職缺會從四個視角產出五個頁面：

| 頁面 | 回答的問題 |
|---|---|
| 職缺解析 `jobs/` | 我符合嗎？適配度幾分？ |
| 客製化履歷 `resumes/` | 履歷要怎麼改？ |
| 公司診斷 `company/` | 公司為什麼現在開這個缺？重要性、急迫性、影響性、期待性、可談判性？**是不是屎缺、機率多少、哪一型？** |
| 職涯適配 `career/` | 這份工作會把我帶到哪裡？符合我的願景嗎？（含互動問答） |
| 面試攻略 `interview/` | 10 題模擬面試＋至少 5 題反問 |

- 🌐 網站：見 repo 右側 About
- 📘 AI 規則：[`AGENTS.md`](AGENTS.md)（總則）＋ [`rules/`](rules/)（細則，做到該步驟才讀）
- 🧰 Skills：[`.claude/skills/`](.claude/skills/)
- ✅ 自動檢查：`python3 scripts/check.py`
